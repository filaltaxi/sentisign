Live demo of [SentiSign](https://github.com/filaltaxi/sentisign). Sign and emotion recognition run in your browser; only the recognised words and an emotion label reach this server, which writes the sentence (Flan-T5-base + LoRA) and speaks it (Kokoro). Trained weights are for research and non-commercial use.
